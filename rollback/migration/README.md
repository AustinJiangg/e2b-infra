## v0.5.1 图表查看与版本规则

正文10张Mermaid流程图与附录3张SVG均支持点击或键盘打开放大弹窗、滚轮缩放、拖动平移、适应窗口和原始大小。支持Esc、关闭按钮或遮罩关闭；关闭后恢复原SVG节点、样式和焦点，避免重复id和矢量图内部引用失效。交互代码随HTML内嵌，无新增运行依赖。

## v0.5.2 看图交互重做

按用户确认的方案，去掉白色面板、顶部工具栏和常驻说明，改为全屏暗色背景、图片居中显示、弱化图题、右上角关闭和底部三个悬浮图标。缩放比例仅在操作时短暂显示，查看放大细节时隐藏图题。

图片从正文位置展开，关闭时收回原处，过渡约200毫秒；遵循系统减少动态效果设置。点击任意图外空白关闭，滚轮以鼠标为中心缩放，双击切换细节与全图，拖动设定边界防止图表移出视野。移动端支持双指缩放、放大后单指拖动，拖动或缩放结束的点击不会误关预览。

图表脚本与样式分别在`tools/diagram_viewer.js`和`tools/diagram_viewer.css`维护，生成器将其内嵌，正式交付仍只需一个HTML。当前版本v0.5.2，未改动功能代码或原始测试结论。
